# Polarbear v0.10.6

## File save correctness

- Coordinate revision checking and file replacement through the existing Apple document coordinator. Serialize overlapping native save entry points and reject stale revisions after another writer commits.
- Preserve macOS POSIX permissions/ownership, ACLs and extended attributes instead of replacing them with temporary-file defaults. Reject read-only files and ACL-denied writes without discarding the open buffer.
- Recheck the destination before publication, avoid recreating an externally deleted document, and keep new-file creation distinct from explicit Save As replacement.
- Retain newer edits while a save is pending. Save As preserves those edits through the document identity transition; saving an older snapshot no longer clears their dirty indicator.
- Show localized permission and uncertain-durability errors. Save-before-close failures keep the tab open.
- Handle failed repository-progress subscriptions and ignore callbacks after disposal. Remove two redundant clipboard tail returns found by strict Clippy.

## Compatibility and limits

No Markdown, database, settings schema, command name, revision format or model migration. Read-only files that were previously overwritten now correctly fail saving. The macOS coordination guarantee applies to cooperating writers; the final disk recheck is not an arbitrary external-writer filesystem CAS. Windows/Linux ACL parity, power-loss recovery and installed-DMG acceptance remain unverified. The existing post-save sync-outbox acknowledgment limitation remains tracked as TD-23.

## Local validation

- Desktop TypeScript and ESLint; 249 Vitest tests; 26 Node script tests; 36 browser tests; Vite production build.
- Desktop Rust: 48 passed, two direct invocations ignored. One is a subprocess fixture exercised twice by the parent two-process test; the other requires a real Memory Engine installation.
- Shared Swift document store: 29 passed. Native tests use real temporary files, mode changes, ACLs, xattrs and two independently launched processes.
- Generated Admin contract, Rust formatting and strict Clippy (`-D warnings`) checks passed. Existing Vite chunk-size warnings remain.
