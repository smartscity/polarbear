# Polarbear v0.10.5

## Correctness and maintenance

- Isolate Context drafts and asynchronous results by workspace. Keep busy state active until all current operations finish, and discard callbacks from disposed sessions.
- Ignore file-revision results after their observer has been disposed.
- Display existing workspace operation feedback, including file-open failures.
- Preserve valid iPhone reading history when another persisted position is malformed.
- Consolidate diagram render caching with bounded successful source/SVG retention, concurrent-request deduplication and retryable failures.
- Remove obsolete plugin list/status styles, declare existing direct Desktop imports and add workspace dependency regression checks.

## Compatibility

No Markdown, settings-key, database-schema, Memory Admin API or model change. Context subpages reset on project changes so drafts cannot cross projects. Workspace remains the launch surface. Existing local Feedback work is not part of this release.

## Local validation

- Desktop: TypeScript, ESLint, 245 Vitest tests, 26 Node script tests, 33 browser tests and Vite build passed.
- iOS: TypeScript, ESLint, 39 Vitest tests, 11 browser tests, storage fixtures, one Rust plugin test and Vite build passed.
- Desktop Rust: 35 passed, one explicit real-Engine test ignored; shared Swift document store: 29 passed.
- Existing x86_64 caption CTest artifacts: seven passed. Python research tests were blocked by missing numpy/soundfile; no ASR qualification or performance improvement is claimed.

See `docs/refactoring/refactoring-report.md` for audit boundaries and unresolved debt. Signed DMG installation, real microphone, ARM qualification and iPhone hardware acceptance were not run locally for this release.
