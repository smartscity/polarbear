# Polarbear v0.10.12

## Changes

- Move recent documents from the main panel into the native File > Open Recent submenu. Preserve existing history, normalize and deduplicate paths, distinguish identical filenames, and support English and Chinese menu labels. Clear Recent removes history without changing disk files, open tabs or unsaved edits.
- Reuse the existing document-open flow when selecting recent files, including active-tab reuse, draft protection and file-loading errors. Keep native menu events aligned with the current history during asynchronous menu replacement.
- Read GitHub Markdown through bounded raw responses at the frozen commit. Keep GitLab publication pending until the complete expected remote snapshot is confirmed, including ambiguous receipts and retry recovery.
- Preserve document identity across batched Save As completions. Retain the fullscreen focus and selection corrections already on main.
- Apply scoped dependency audits and bind release gates and platform builds to one resolved candidate commit.
