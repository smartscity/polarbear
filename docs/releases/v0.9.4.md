# v0.9.4: Canonical vocabulary notebook integration

## Root cause

Reader could save an unresolved sense when a dictionary query returned multiple
matches. Vocab persisted that capture outside vocabulary membership, while the
notebook counted only membership. Consequently a successful capture could coexist
with zero dataset words and a disabled study action.

## Changes

- Reader selects an existing saved sense or a dictionary result and submits through
  the existing native outbox. The receiver resolves missing senses and creates a
  canonical local entry when no dictionary match exists.
- Vocab 0.3.2 exposes notebook membership through its existing dataset, statistics,
  and study interfaces. It retains the original learning identity when additional
  senses of the same word are captured.
- Incomplete entries support explicit self-assessment in the existing session
  engine and manual enrichment without changing their identifiers. Definitions
  are not invented and bundled dictionary entries are not overwritten.
- Reader supports removing and re-adding a favorite. Durable request receipts
  distinguish transport retries from new user actions.
- Source context is displayed as plain text; equivalent filenames and titles are
  not repeated. Original source records remain preserved.

## Migration

Vocab backs up both databases before resolving legacy pending captures. Migration
is retry-safe, preserves source metadata, and restores snapshots after a reported
failure. User schema v9 adds request receipts. Removing membership does not erase
reading records or immutable answer history. Desktop never opens Vocab databases.

## Installed-app acceptance

Update both applications, then save `growth`, open the notebook, and start a
one-word session. Complete it and reopen Vocab to check history. Save the same word
from a second article, verify one dataset word and both sources, then remove and
re-add it. Repeat with a term missing from the dictionary and complete its fields.
Verify existing pending captures migrate and ordinary datasets still start.

## Limits

- Updating Desktop alone cannot repair the old Vocab receiver; both releases are
  required. A legacy null-sense acknowledgement is not reported as a completed save.
- Incomplete entries are usable, but automatic background dictionary enrichment is
  not implemented. Local entries can be edited; bundled dictionary content remains
  protected.
- Notebook membership is a live dataset projection. Dataset-management operations
  such as renaming or deleting the system notebook are intentionally unavailable.
- Reading sources remain local. This change does not add cross-device replication
  of source records or newly supplied dictionary content.
- Existing build chunk-size and translator worker externalization warnings remain.
