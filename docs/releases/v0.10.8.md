# Polarbear v0.10.8

## Document reload safety

- Unify automatic file reload, explicit Reload from Disk and post-sync reload behind document-local result permissions.
- Reject obsolete reads after editing, document closure/reopening, path or revision changes. Keep Editing now revokes a pending explicit reload before dismissing the dialog.
- Keep local edits and show the conflict choice when typing during reload. Preserve valid explicit discard and distinguish current read failures from obsolete completions.
- Report retained local edits after remote sync instead of claiming every document was reloaded. Preserve existing Markdown, persistence and native IPC formats.

## Validation

Local macOS x86_64: TypeScript, ESLint, 265 Vitest tests, 48 browser tests, 51 native tests, 26 Node tests, Rust formatting, strict Clippy, generated Admin contract and the production frontend build passed. The native subprocess fixture is exercised by its parent test; the opt-in real Memory Engine test was not rerun in this frontend-only batch. Existing large-chunk build warnings remain.

No data migration, new dependency, caption model change or release-gate relaxation. Browser reload regressions exercise the actual App/editor with controlled native IPC; they do not certify installed-DMG behavior or cancel already accepted filesystem IO. Broader document-session refactoring and remaining menu/table resource investigations are tracked explicitly.
