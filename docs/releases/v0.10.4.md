# Polarbear v0.10.4

## Desktop Navigation and Preferences

- Start every main window in Workspace instead of Context.
- Keep explicit system language/theme preferences ahead of legacy settings and
  stop persisting resolved theme defaults during startup.
- Protect Context settings from unloaded defaults, refresh-driven draft loss
  and stale asynchronous reads after a confirmed save.
- Add persistent Recent navigation for the last 20 Markdown documents, including
  deduplication, native reopening, removal, clear and unavailable-file feedback.
- Organize Settings into General, Live Caption and Privacy sections; separate
  audio source from history and display configured shortcuts with Apple symbols.
- Keep caption switches synchronized with native state without automatically
  resuming recording on application launch.

## Validation

Local TypeScript, ESLint, production Vite build and Rust formatting passed.
Vitest: 238 passed. Node tests: 24 passed. Browser tests: 30 passed.
Rust tests: 35 passed, 1 real-Memory-Engine integration test ignored.

The release workflow must still validate and build the native DMG. Local browser
tests mock native capture and Memory Admin IPC; they are not native permission
or installed-Engine restart acceptance. Caption accuracy and latency policy are
unchanged by this release.

Pinning and automatic relocation of recent files are deferred. The existing
native file-access adapter remains responsible for permissions; no new
security-scoped bookmark implementation is claimed.
