# Polarbear v0.10.7

## Document safety

- Preserve successful local saves when optional sync bookkeeping fails. Report a sync warning with the committed revision instead of an ambiguous save failure.
- Use the same guarded document-save path for Sync. Pending saves and newer unsaved edits pause sync; no duplicate stale save or blanket dirty-state reset.
- Keep the active document when a file-tree read fails. Discard superseded read completions after newer navigation without reporting the recent file as missing.
- Refuse workspace replacement while unsaved documents remain, including edits made during folder loading. Prepare the target workspace before changing the current state.
